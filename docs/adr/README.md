# Architecture decision records

Record consequential architectural decisions here. Product explorations and unvalidated alternatives belong in [proposals](../proposals/README.md); the overall specification is [plan.md](../../plan.md).

Use `NNNN-short-title.md`, choosing the next unused number. Copy [TEMPLATE.md](TEMPLATE.md). Record the decision's status and basis; a recorded draft is not an accepted decision. Preserve accepted history: a replacement ADR should link to the older record and mark it superseded.

Keep records concise. Explain the problem, chosen approach, alternatives, consequences, and supporting evidence. Routine code changes do not need an ADR.
